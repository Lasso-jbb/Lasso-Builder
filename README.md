# Lasso-Builder

## Branches

| Branch    | Formål                                              |
|-----------|-----------------------------------------------------|
| `main`    | Produktion. Kun testet kode fra `staging` merges hertil. |
| `staging` | Test og verifikation før release til `main`.        |

Feature-arbejde laves på egne branches, som merges ind i `staging` via pull requests.
